# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public GitHub issues.

Use [GitHub private vulnerability reporting](https://github.com/zakaihamilton/repnix/security/advisories/new) to send a confidential report. Include a clear description, the affected RepNix version, reproduction steps, and any suggested mitigation.

We will acknowledge reports, investigate them privately, and coordinate a fix and disclosure with the reporter. Please give us a reasonable opportunity to resolve the issue before sharing details publicly.

## Supported versions

Security fixes are provided for the latest published version of RepNix.
